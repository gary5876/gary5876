# 안녕하세요, 백엔드 개발자 Junseo입니다 👋

**Spring · Kotlin · Python 백엔드**를 만들고, **코딩에이전트와 LLM으로 개발 프로세스를 자동화**합니다.
API 설계부터 DB 모델링, 클라우드 배포·CI까지 서비스를 끝까지 만들어 운영하는 것을 좋아합니다.
